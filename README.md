# BlogSphere

A full-stack blogging platform built with React and Appwrite.

## Features

- User authentication (login / signup)
- Create, edit, delete blog posts
- Rich text editor (TinyMCE)
- Image upload
- Protected routes
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```
